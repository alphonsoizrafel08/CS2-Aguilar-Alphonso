# Electricity calculator
## This program calculates the customer's name, electricity consumption in kWh, and total bill in PHP.

## Version 1 - Original code without input validation
- Input: Accepts a customer's name, previous meter reading, and final meter reading.
- Process: Calculates and displays the customer's name, electricity consumption in kWh, and total bill in PHP.
- Output: Customer's name, electricity consumption in kWh, and total bill in PHP.
- Does not include input validation

## Version 2 - Updated code with input validation
- Input: Accepts a customer's name, previous meter reading, and final meter reading.
- Process: Calculates and displays the customer's name, electricity consumption in kWh, and total bill in PHP.
- Output: Customer's name, electricity consumption in kWh, and total bill in PHP.

## Input validation
- Checks if the customer's name is empty.
- Checks the previous reading if the number is less than 0.
- Checks the current reading if the number is less than the previous reading.
